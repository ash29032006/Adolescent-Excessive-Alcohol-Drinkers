# Classifying Adolescent Excessive Alcohol Drinkers from fMRI Data

UE24CS352A Machine Learning mini project (PES University), problem 35.
Reference: Kim, Liu, Noh, *Classifying Adolescent Excessive Alcohol Drinkers from fMRI Data*, Stanford CS229.

We reproduce the paper's pipeline (per-region signal range + demographics + logistic regression), test stronger
functional connectivity features, and check two failure modes the paper hints at: reliance on **age** and on
**scanner site**.

## Dataset: why ABIDE and not NCANDA

The paper uses NCANDA. Access needs an NIAAA Data Use Certification plus a committee review (up to 30 days), which
does not fit the project timeline. We use **ABIDE Preprocessed** (CPAC pipeline, band-pass filtered, quality checked,
Craddock 200-region atlas) through `nilearn.datasets.fetch_abide_pcp`. It is the same kind of data (resting-state fMRI,
one time series per brain region, multi-site, imbalanced), but the label is **autism (1) vs control (0)**.
The pipeline is dataset agnostic: switching to NCANDA only needs a `load_ncanda()` in `src/data.py` that returns the
same `(timeseries, labels, phenotype)` triple.

## Run

```bash
python download_data.py              # builds data/timeseries.npy (raw ABIDE files are already in data/, ~15 s, no download)
python run_experiments.py            # all experiments -> results/, figures/, models/  (~1 h, tangent is the slow part)
python make_report.py                # report/writeup.pdf, report/slides.pptx, results table below
python demo.py                       # live demo, offline, < 2 min
```

The repo already contains the ABIDE region time series (`data/ABIDE_pcp/`), labels, phenotype and the trained
demo model (`models/`), so after `python download_data.py` the demo runs straight away. Only
`data/timeseries.npy` is not committed (257 MB, over GitHub's file limit); `download_data.py` rebuilds it from the
included files.

Useful options:

```bash
python run_experiments.py --experiment baseline      # or connectivity | tangent | deep
python run_experiments.py --subset 80                # smoke test on 80 random people
python demo.py --person 5 --no-plot
```

Experiments can be run one at a time: each run replaces only its own rows in `results/results.csv`.

## Method

| Step | What | Where |
|---|---|---|
| Features | range (max minus min per region, the paper's feature), correlation connectivity (19,900 region pairs), tangent connectivity, demographics (age, sex, one-hot site) | `src/features.py` |
| Models | L2 logistic regression, linear SVM, RBF SVM (all `class_weight="balanced"`), majority-class dummy | `src/models.py` |
| Deep baseline | small 1D CNN on z-scored time series, random 64-step crops, global average pooling | `src/deep.py` |
| Evaluation | 5-fold stratified CV and 5-fold site-grouped CV; accuracy, F1, ROC AUC (mean ± std) | `src/evaluate.py` |

**No leakage.** Each model is `features -> GridSearchCV(StandardScaler -> classifier)`. Learned features (tangent
reference) are fit on the outer training fold only; the scaler and `C` are tuned by an inner 3-fold CV inside that
fold. Correlation, range and demographics are computed per person, so they are safe to precompute.
All people are used; imbalance is handled by class weights. Seed 42 everywhere.

**Research questions:** (1) reproduce the paper's baseline, (2) better features (connectivity), (3) age ablation
(brain only / demographics only / both), (4) site effect (stratified vs site-grouped CV), (5) small deep-learning
baseline.

## Results

Best model per feature set (5-fold CV). "Site" columns hold out whole acquisition sites. Generated by
`make_report.py` from `results/results.csv`; every model and CV scheme is in that file.

- Best model: tangent+demo features with Linear SVM, accuracy 0.675 ± 0.021 and ROC AUC 0.740 ± 0.024 (stratified 5-fold CV), against 0.537 accuracy and AUC 0.5 for always guessing the majority class. Out of fold it caught 273/403 autism cases (sensitivity 0.68) and 315/468 controls (specificity 0.67).
- Paper reproduction: range features + demographics with logistic regression gave accuracy 0.563 (AUC 0.594); range features alone gave 0.583 (AUC 0.597). The paper reported 0.713 with age and 0.538 without on NCANDA (different task, so not directly comparable).
- Better features: correlation connectivity beats the paper's range features (best AUC 0.733 vs 0.620).
- Age ablation: demographics alone reach AUC 0.532; tangent brain features alone reach 0.740 and 0.740 with demographics added. Unlike the paper, the prediction is carried by the brain features, not by age.
- Site effect: holding out whole sites moves the best model's AUC from 0.740 to 0.741 (+0.001). The model transfers to unseen scanners.
- Deep learning: the 1D CNN on raw time series reached accuracy 0.634, AUC 0.705, below the linear models on connectivity: as in the paper, simple models on derived features win on small fMRI data.
